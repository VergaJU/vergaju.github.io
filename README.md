# vergaju.github.io

Personal portfolio of **Jacopo Umberto Verga** — AI Research Scientist &amp; Computational Biologist.

Built with vanilla HTML, CSS, and JavaScript. No frameworks.

## Structure

| Path | Content |
|------|---------|
| `/index.html` | Portfolio homepage |
| `/resume/VergaJU_resume.pdf` | CV download |
| `/finance_bro/finance-bro.html` | FinanceBro investment dashboard |
| `/Bone_Marrow_QC/quality_control.html` | scRNA-Seq QC reports hub |
| `/about-ai.md` | AI context file for LLM crawlers |
| `/LLMs.txt` | LLM instructions (llmstxt.org) |
| `/feed.xml` | Atom feed |
| `/robots.txt` | Robots exclusion |
| `/sitemap.xml` | XML sitemap |

## Subdirectory reports

- `Bone_Marrow_QC/mm/` and `Bone_Marrow_QC/healthy/` — Pandoc-generated QC reports
- `DGE_test/` — Differential gene expression analysis reports
- `TFs/scenic/` — Transcription factor enrichment reports
- `04 Portfolio/assets/images/` — Site images

## Tech

- **Icons:** Font Awesome, Devicon, Academic Icons
- **Font:** DM Sans (Google Fonts)
- **SEO:** OpenGraph, Twitter Cards, JSON-LD structured data
